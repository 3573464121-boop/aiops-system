# 故障回放实验报告 v1

实验日期：2026-09-02  
案例集：`eval/replay-dataset-v1.json`  
案例版本：`eval-v1`  
被测模型：`deepseek-chat`  
独立判官：`qwen2.5:7b`（本地 Ollama）

## 实验设置

对 10 个固定故障案例分别运行三种配置：

- `full`：Agent 工具循环与 BM25 + 向量 RRF 检索。
- `bm25`：Agent 工具循环与 BM25 检索，不使用查询向量。
- `no-agent`：不调用工具和证据的单轮模型回答。

每个案例与配置只取最新一次有效结果统计。`order-2 / bm25` 首次执行发生模型调用超时，失败记录保留在数据库中，不纳入下表；重跑成功，耗时 8.98 秒且工具失败数为 0。

## 解释与限制

完整系统在该小规模合成数据集上优于 BM25 消融组和无 Agent 基线，但 10 个案例不足以支持一般化结论。完整系统与 BM25 的差距只有 1 个案例，需要扩大真实脱敏案例集并执行重复实验后再进行统计检验。

无 Agent 组的忠实度均为 0，但独立判官同时给出“无幻觉”，触发了 10 条确定性质量告警。这说明本地判官对“缺少证据”和“产生幻觉”的定义存在不一致。该字段不能直接作为论文结论，必须经过人工复核，或使用更强的独立判官重复评估。

当前所有 `eval-v1` 回放结果均应保持待复核状态。只有人工复核为“已采纳”的结果才能通过页面导出 JSON 或 CSV。
